# Agent CLI Updater

A simple Windows utility for updating agent CLI tools.

## Usage

Run the supplied PowerShell script:

~~~powershell
.\update-agent-clis.ps1
~~~

## First Run

Register the scheduled task to update tools automatically every day at 02:00:

~~~powershell
.\register-agent-cli-updater-task.ps1
~~~
